✈️ 机票低价监控系统 · 设置（云端版）

本页直接读写 GitHub 仓库里的 config.json。改完保存，云端每 2 小时自动用新设置跑。

首次使用请先在下面「连接 GitHub」填写你的令牌（PAT）。

·连接 GitHub

没有 PAT？去 GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，勾 repo 全选，生成后粘贴到这里。此令牌能读写你的 ticketmonitor 仓库，请勿在公共电脑勾选「记住」。

1出发地（可多个 · 按机场代码区分）

同一城市的不同机场要分别添加（如上海拆 SHA 虹桥 与 PVG 浦东），每个出发地用机场三字码唯一标识——这是唯一识别码。监控会为每个出发地各跑一遍，互不串味。下方「从预设机场添加」可快速加入常见机场。

2出行窗口

3行程天数

4价格分档阈值（元 / 往返总价，仅用于网页展示推荐）

例：A 档 ¥1000、B 档 ¥2000 → 只看往返 ¥2000 以内的航线，并分两档推荐。超过 B 档上限的航线直接不显示。真正触发推送的是第 7 节的阈值。

5排除国内廉价航空

勾选的航司会从结果中剔除（保留亚航、越捷等外国低成本航司）。

6监控目的地（航线）

勾选要监控的目的地（默认全选 = 仓库内置 130 城全量）。取消部分则只盯你选的。保存即生效，无需改代码。

7实时特价提醒（触发式推送）

满足「价格≤上限 或 折扣≥比例」的航线会立刻推微信；已达标但近期提醒过的不会重复刷屏，只有出现更低价或冷却期满才再推。下一轮运行（每 2 小时）即按新阈值评估。

8微信提醒（Server酱）

推送密钥 SCT_SENDKEY 存在仓库 Secrets 里（不在 config.json，避免在网页暴露）。
去仓库 → Settings → Secrets and variables → Actions → New repository secret：名称 SCT_SENDKEY，值填你的 SendKey（sct.ftqq.com 微信扫码关注「方糖」获取）。
保存设置后下一轮运行即生效；想验证密钥是否正确，可在下面临时填一次 SendKey 发测试（不保存）。

保存 = 用 GitHub API 提交 config.json 到 node 分支；GitHub Actions 下一轮（每 2 小时）自动用新设置跑。
